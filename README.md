# 桥梁病害照片配准与三维贴图系统

纯 TypeScript + WebGL2 实现的桥梁检测图像处理系统：无人机照片带 POS/云台角粗投，
人工/自动同名点精配准，投影纹理烘焙到参数化桥梁构件，并在正射病害图上登记、
量测、复检对比与技术状况评定。无第三方三维/视觉库依赖（矩阵、LM、PnP、着色器全部自写）。

## 技术栈

- Vite + TypeScript（strict），零运行时依赖
- WebGL2 自写着色器：场景离屏渲染、径向畸变后处理、投影纹理
- IndexedDB：桥梁档案、构件网格、照片 Blob、病害、评分全部本地持久化
- Playwright：端到端精度验收

## 七个页面

| 路由 | 功能 |
| --- | --- |
| `#/archive` 桥梁档案 | 按桥型（简支 T 梁/小箱梁、连续箱梁）录跨径、跨数、梁片数，参数化生成主梁、横隔板、盖梁、墩柱、支座，自动编号 |
| `#/modeling` 构件建模 | 三维浏览、构件树、表面米制尺寸、烘焙纹理回贴 |
| `#/registration` 照片配准 | 待处理清单（缺 POS/过曝/对不上）、标志检测、PnP 解算、逐点重投影残差、人工同名点、纹理烘焙 |
| `#/defects` 病害登记 | 正射病害图上绘制或照片上绘制反算局部坐标，裂缝/剥落/渗水/蜂窝四类，缝宽按 GSD 换算毫米 |
| `#/comparison` 复检对比 | 两期正射图叠加，自动识别裂缝延伸与新增病害 |
| `#/report` 检测报告 | 构件→部件→部位→全桥评分，扣分可点回三维定位，可打印 |
| `#/selftest` 精度自测 | 合成两期数据，端到端跑通并核验精度硬指标 |

## 核心算法

- **参数化几何**：所有表面为平面/圆柱面，带解析双向映射（3D ↔ 米制 UV），正射展开比例尺即实际尺寸
- **PnP**：Hartley 归一化 DLT 给初值，Levenberg–Marquardt（数值雅可比、Huber 鲁棒核、信任域）
  联合优化旋转向量、平移、焦距、径向 k1/k2 与切向 p1/p2；含 π 角稳定轴角反算、平面点集法向翻转信任域
- **标志检测**：亮环 + 暗核双检测器融合，亚像素暗度加权质心，粗 POS 投影一对一身份匹配
- **纹理烘焙**：逐纹素解析反投影，空间哈希网格加速的射线遮挡判定，入射角余弦² + 距离倒数加权，多图无缝融合
- **评定**：JTG/T H21 思路的构件修正扣分 → 部件等权平均 → 全桥加权 D_r

## 精度指标（`npm test` 自动验收）

- 重投影 RMS ≤ **1.5 px**（实测平均约 0.06 px，单张最大 ≤ 1.31 px）
- 正射病害图裂缝长度量测相对误差 ≤ **2%**
- 异常照片（过曝、缺 POS）不参与贴图，强制进入待处理列表

## 常用命令

```bash
npm install
npm run dev        # 开发服务器
npm run build      # 类型检查 + 生产构建
npx playwright test   # 端到端精度验收（先 npm run dev 起服务）
```

## 快速验证流程

打开「精度自测」页，依次点击：
1. 生成合成数据集（三跨小箱梁、两期照片、POS 噪声 0.35m/1.2°、含过曝与缺 POS）
2. 自动配准全部照片
3. 烘焙投影纹理
4. 裂缝量测与精度评定

全部指标显示「达标」即整条流水线（渲染→检测→PnP→烘焙→量测）符合验收要求。

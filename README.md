# 桥检三维配准贴图系统

纯 TypeScript + WebGL2 实现的桥梁无人机照片配准、三维贴图与病害追踪系统，无第三方三维/几何库，
所有数学（SVD、EPnP、Levenberg–Marquardt、光线投射、ENU 大地转换、着色器）均在本仓库内实现。

## 运行

```bash
npm install
npm run dev      # http://127.0.0.1:5173
npm run build    # 类型检查 + 生产构建
```

打开后点右上角 **「生成合成测试数据」**，会离屏渲染一座三跨小箱梁（3 跨 ×20m、4 片梁/跨、54 个构件）、
两期共 24 张照片（含 POS 噪声、过曝、缺 POS 异常样本）和已知长度裂缝并写入 IndexedDB，再点
**「运行验收自检」**，结果同时输出到页面与浏览器控制台。

## 六个页面

| 页面 | 功能 |
|---|---|
| 桥梁档案 | 按桥型(简支T梁/小箱梁/连续箱梁)、跨径、梁片数、墩高等参数化生成主梁/横隔板/盖梁/墩柱/支座/桥台，自动编号 S跨-#梁、P墩-GL 等 |
| 构件建模 | WebGL2 三维浏览、构件树点选、包围盒/三角面/可展开表面信息 |
| 照片配准 | POS 粗投 → 照片/模型同名点联选(≥4) → EPnP+LM 联合解算位姿/焦距/k1,k2 畸变，逐点列残差，超 1.5px 标记，待处理列表收纳过曝/缺POS/残差超标照片，批量烘焙贴图 |
| 病害登记 | 在已配准照片上画裂缝/剥落/渗水/蜂窝，像素射线反算到构件局部坐标，裂缝宽度按 `像素宽×物距/fx` 换算毫米，切换照片病害仍贴在原位 |
| 复检对比 | 同构件两期正射病害图叠加(滑块调透明度)，自动列出裂缝延伸量、新增/消退病害 |
| 检测报告 | 构件→部件→桥面系/上部/下部→全桥评分与等级，扣分明细可点回三维定位，导出 Markdown/JSON |

## 核心算法

- `src/core/svd.ts` — 单边 Jacobi SVD、特征分解、正定方程组
- `src/core/camera.ts` — 针孔+径向畸变(k1,k2)模型、EPnP（4 控制点 + Gauss–Newton β 精化 + 全点 Horn 定向）、
  10 参数 LM 联合优化（fx,fy,k1,k2,SO3 增量姿态,光心），中心差分雅可比
- `src/core/geo.ts` — WGS84 经纬度/高程 ↔ 局部 ENU
- `src/core/raycast.ts` — Möller–Trumbore 三角形光线投射
- `src/render/` — 自定义 GLSL 着色器；投影纹理烘焙含深度图可见性遮挡、入射角/拍摄距离加权融合、LOD 纹理分页

## 验收指标（合成数据实测）

- 重投影残差：12 张照片 RMS 均值 **0.368px / 最大 0.440px / 100% ≤ 1.5px**
- 正射病害图裂缝长度误差：**0.00%**（验收线 2%）
- 24 张照片中 2 张缺 POS、1 张过曝全部进入待处理列表且标记保留
- 复检自动识别 1 条延伸裂缝、1 条新增病害
